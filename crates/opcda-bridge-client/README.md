# opcda-bridge-client

Cross-platform command-line client for an
[`opcda-bridge`](https://github.com/bytehound-labs/opcda-bridge) gateway.

Install it with Cargo:

```sh
cargo install opcda-bridge-client
```

Use `opcda-bridge-client --help` for connection, browsing, reading, and writing commands. Prebuilt
platform binaries are available from the repository releases page.
